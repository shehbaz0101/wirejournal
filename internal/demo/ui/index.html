Crash an agent. Watch one lane forget, and one remember.

Both lanes run the same 16-step triage job and send one email. Press the button to SIGKILL both agents. The left lane replays from a journal (tokens stay put, one email). The right lane starts over (it pays again and sends a second email).

Demo uses 16 steps so the counter is readable in half a minute. The published benchmark is the same agent at 200 steps. Tokens and inbox counts come from the mock LLM and mock mail, not from the proxy.
